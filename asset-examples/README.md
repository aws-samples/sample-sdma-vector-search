# Asset Examples

This directory is for 3D asset files used with the Extension. Assets are not included in the repository due to file size.

## Download Free Assets

| Source | Description |
|--------|-------------|
| [KayKit Furniture Kit](https://kaylousberg.itch.io/kay-kit-furniture) | Low-poly furniture (GLB) — used in demo screenshots |
| [Sketchfab](https://sketchfab.com/features/free-3d-models) | Free 3D models in various formats |
| [Polyhaven](https://polyhaven.com/) | CC0 models, textures, and HDRIs |

## Supported Formats

Place `.glb`, `.gltf`, `.fbx`, `.obj`, or `.blend` files in a subdirectory and upload with:

```bash
./scripts/test-upload.sh -d asset-examples/<your-folder>/
```
